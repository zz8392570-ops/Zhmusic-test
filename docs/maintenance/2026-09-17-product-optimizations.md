# 产品优化交付与验收（2026-09-17）

本次落实产品评审中的 P1/P2；P0 首次使用引导暂不实施。

## 已实现

| 功能 | 用户可见变化 |
| --- | --- |
| 音质 | 区分首选音质和实际播放音质；单首降级不改变下一首的偏好。 |
| 音源等待 | 播放页显示获取音源、换源、尝试其他音质的状态；支持取消、换源、下一首及失败重试。获取音源总等待上限为 20 秒，不包含音频缓冲时间。 |
| 备份恢复 | 设置中可导出和导入 JSON，预览收藏、歌单等数量，选择合并或覆盖，以及是否恢复设置。输入先校验，写入失败尝试回滚。 |
| 在线搜索 | 五个平台并行搜索，先到的结果可立即使用；后续结果追加，重复录音保持已有结果身份和位置，保留 live/remix 等版本区别。 |
| 我的音乐 | 支持按歌曲、歌手、专辑和歌单搜索；歌曲显示所属歌单，可以直接播放。 |
| 离线下载 | 支持批量保存、排队、进度、取消和重试；最多同时下载两首，同一歌曲的不同音质串行处理。重启后的未完成任务标为中断，由用户继续并重新获取播放链接。 |
| 缓存管理 | 自动缓存可选 256 MB、512 MB、1 GB、2 GB，默认 1 GB；主动保存、历史离线文件和正在播放的文件受到保留保护。清理自动缓存保留主动离线保存。 |
| 导航与说明 | 统一“榜单”“我的音乐”用语，补齐中英文提示，README 更新平台范围和功能说明，旧截图明确标注为历史示意。 |

备份包含个人歌曲记录、歌单、近期播放和允许恢复的设置，不包含音频文件、音源脚本、凭据、封面图片文件或下载任务。恢复本地歌曲记录不等于恢复音频；更换设备仍需重新导入或下载。

取消会立即结束调用者的等待并忽略迟到结果。LX 音源的关联 HTTP 请求会中止；没有取消接口的 CommonJS 脚本可能仍在后台完成第三方请求。下载继续会重新下载文件，不承诺从已有字节续传。保留文件可能使磁盘实际占用暂时超过自动缓存上限。

## iPhone 验收步骤

1. 首选 FLAC，使用仅支持较低音质的音源播放；确认实际音质降低而设置仍为 FLAC，下一首仍先尝试 FLAC。
2. 使用慢音源，分别点取消、换源和下一首；确认旧请求不会恢复播放或覆盖新歌曲，超时后可以重试。
3. 在线搜索观察先到结果立即可点，后到结果不挤动已有录音；切换关键词时不会出现旧查询结果。
4. 在“我的音乐”按歌手和专辑搜索，检查所属歌单及点击播放；验证中文、英文和深浅主题。
5. 导出备份到系统分享面板，导入检查预览；分别尝试合并、覆盖和不恢复设置。无效文件必须提示错误并保留原数据。
6. 批量保存歌曲，取消排队及运行中的任务、重试失败任务，退出重启后继续中断任务；确认刷新链接且取消后不会新增离线记录。
7. 保存一首离线歌曲并播放另一首自动缓存歌曲，降低容量、清理自动缓存；确认离线保存及当前播放文件仍存在，其他自动缓存按时间淘汰。
8. 验证锁屏、后台、耳机控制、系统音量及精准跳转，确认原有播放行为没有退化。
