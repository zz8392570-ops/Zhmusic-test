# 首次使用与备份可靠性

- 首次进入显示配置音源、测试音源、搜索播放入口，可跳过；完成标记仅保存在本机。
- 自动备份持久化最近成功时间、失败原因与连续失败次数。备份页面显示状态并提供重试，连续失败两次时主界面提示。
- WebDAV 保存及网络操作仅接受 HTTPS，禁止自动重定向。历史 HTTP 地址仍可打开编辑，但不会发送凭据。
- 自动备份成功清除失败状态；当天已备份的跳过操作不会修改成功时间。手动上传也更新状态。
- 新增受控验证覆盖 HTTP 拦截、历史配置迁移、重定向策略、自动备份状态、重复触发合并及失败恢复。

真机验收：首次安装逐步配置并播放；重启确认引导关闭；错误 WebDAV 凭据触发两次前台备份，检查首页提醒和失败原因；修正凭据立即重试，确认提醒消失；使用旧 HTTP 配置确认可编辑且上传被阻止。

本地验证：`npm run validate` 通过（lint、TypeScript、15 组核心检查）。本次 WebDAV 网络/状态专项共 10 项通过。两项真实符号链接案例因 Windows 权限跳过。iOS 原生编译与安装验收以 GitHub 构建及真机结果为准。
