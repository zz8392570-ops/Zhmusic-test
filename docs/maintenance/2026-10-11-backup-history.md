# WebDAV 历史恢复

- 使用 Depth 1 的 PROPFIND 列出当前备份目录下的 daily 快照，按日期倒序展示。
- 仅接受直接位于该目录、日期有效且属性读取成功的 ZhMusic-YYYY-MM-DD.json 文件；跨域、子目录、目录项及异常 XML 不作为恢复目标。
- 按日期在本机构建下载路径，不直接请求服务器列表提供的地址。下载经过大小及备份格式、歌曲、设置字段校验后进入现有恢复预览。
- 预览显示来源，说明备份不含音频、音源脚本及封面文件。合并、覆盖和恢复设置沿用现有确认及存储回滚逻辑。
- 缺少 daily 目录显示空列表；目录响应上限 2 MB。不会自动删除历史快照。

设备验收：配置有历史快照的 WebDAV，查看日期与大小、选取旧日期预览并合并；验证无历史、权限错误、无效文件的提示。覆盖恢复需确认且只应用已校验内容。

本地验证：`npm run validate` 通过，包含 lint、TypeScript 与 15 组核心检查；WebDAV 专项 11 项通过。两项真实符号链接案例仍因 Windows 权限跳过。XML 解析使用锁定的 `@xmldom/xmldom@0.8.15`，无需新增原生模块。
